# Branding Guidelines: secQ Website

## 1. Design Philosophy
This project strictly follows an Apple inspired design language based on the Human Interface Guidelines. The core principles are clarity, minimalism, depth, and deference to content.

Clarity: Focus on the data. Security reports must be legible, clean, and immediately understandable.
Deference: The UI should step back and let the security findings be the primary focus. Use ample whitespace and remove visual clutter.
Depth: Use subtle layering, translucency, and soft drop shadows to establish a clear visual hierarchy between the background, navigation, and content cards.

## 2. Typography
The typography relies on clean, modern, and highly legible system fonts to mirror the Apple ecosystem.

Font Family: Use the native system font stack utilizing SF Pro Display and SF Pro Text, falling back to Helvetica Neue or Arial.
Headings: Use SF Pro Display. Keep weights at Semibold or Bold. Ensure clean, structural scaling for vulnerability scores and dashboard metrics.
Body and UI Elements: Use SF Pro Text. Keep weights Regular or Medium. Maintain a line height of 1.5 for optimal readability on lengthy security reports.

## 4. Color Palette
The color palette is neutral, premium, and sophisticated, using the main brand color as a sharp and deliberate accent.

Main Brand Accent: #c0ff00. Use sparingly for primary call to action buttons, active navigation states, and key graphical highlights.
Base Background: #F5F5F7. A soft and warm light gray for the main application background.
Surface Background: #FFFFFF. Pure white for cards, modals, and content containers.
Primary Text: #1D1D1F. Deep and soft black for maximum legibility without the harshness of pure black.
Secondary Text: #86868B. Smooth gray for metadata, timestamps, and subtle labels.
Semantic Colors: Use Apple standard semantic colors for vulnerability severities. Critical is #FF3B30. High is #FF9500. Medium is #FFCC00. Low is #34C759.

## 5. UI Components and UX
Buttons: Use pill shaped or softly rounded rectangles with a 12px border radius. Remove all heavy gradients and harsh borders. Use solid colors with a very subtle scale down animation on click to mimic haptic feedback.
Cards and Surfaces: Use continuous curve rounded corners, often called squircles, with a 16px to 24px radius. Apply very soft and diffused drop shadows to separate them gently from the base background.
Navigation: Implement a translucent top navigation bar or sidebar with a distinct background blur to mimic Apple frosted glass material effect. Ensure active states are indicated by soft gray backgrounds or the #c0ff00 accent.
Data Presentation: Present security data in clean and uncluttered list views. Charts should be minimalist without unnecessary borders or heavy grid lines. Use whitespace to separate sections naturally rather than relying on dividing lines.
